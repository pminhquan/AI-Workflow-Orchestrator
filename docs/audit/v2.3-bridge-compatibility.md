## Documented future boundaries — design only

Official sources checked 2026-11-05:

- [Antigravity Additional Terms, item 6](https://antigravity.google/terms) restrict third-party software accessing the consumer service, including OAuth wrappers. This task does not reinterpret the existing bridge as an approved integration.
- [Native subagents](https://antigravity.google/docs/subagents) describes app-owned delegation and inherited permissions. It does not establish that V1's private agentapi/navigation mechanism is supported.
- [Official headless CLI](https://antigravity.google/docs/cli/headless/) documents print/JSON/streaming modes and cached authentication. That is a separate documented surface; applicable account/terms authorization and target/session semantics for a Codex caller remain UNKNOWN here. It does not prove supported attachment to the currently focused Desktop conversation. No CLI invocation or installation occurred.
- [Python SDK](https://antigravity.google/docs/sdk/overview) documents a separate runtime with API-key or enterprise/cloud authentication; [managed Antigravity agent](https://aistudio.google.com/docs/antigravity-agent) documents a Gemini API agent with a remote sandbox, tool loops, usage and budget controls. Both are documented future candidates, not use of the consumer Desktop session. Account availability, exact scopes and cost/credit authorization are NOT VERIFIED locally.

If separately approved, choose one official surface and pin its SDK/API/CLI version and terms/account route. Reuse existing brief/result contracts; bind the actual workspace/environment and session ID; distinguish accepted/running/finished/result; enforce real host scopes; verify parent-side diff/tests; record attempt IDs and uncertain-delivery behavior; define supported cancellation and rollback. Require explicit data-transfer, auth, budget/billing and installation scope before any call. Keep consumer session tokens private and never duplicate the V1 ledger or add a parallel lifecycle merely for reporting. No executor, keys, billing, sidecar, dashboard or activation is added in V2.3.
